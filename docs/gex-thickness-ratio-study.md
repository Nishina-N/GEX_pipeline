# GEX厚み比 検証レポート（タスク#7 ステップC）

検証日: 2026-08-08 / データ期間: 2026-06-11〜2026-08-07（41営業日、常時収録12銘柄）
検証スクリプト: `scripts/analyze_thickness_ratio.py`

## 目的

レジーム（＋γ/−γ）の確信度に使う「厚み」を、絶対しきい値でなく**銘柄ごとの平常比**で測れるようにする。
当初仮説は「確信度 ∝（SpotとHVLの距離）×（|totalGEX|の厚み）」。

## 結論（要約）

1. **`|totalGEX|` を厚みの指標に使ってはいけない**。符号付き合計の絶対値なので、板が厚くても＋/−が相殺すればゼロ近傍になる。
2. 代わりに **`near` = Spot±10%のストライクにおける Σ|netGEX|（グロスガンマ近傍版）** を使う。
3. 厚み比と翌日値幅の関係は**単調でなくU字**。当初仮説「厚い＝安定／薄い＝不安定」は**支持されなかった**。
4. **効くのは個別銘柄のみ。指数では判別力がない。**

## 1. |totalGEX| は厚みを表さない

2026-08-07 時点の `net/gross` 比（小さいほど板が相殺されている）:

| 銘柄 | net(=\|totalGEX\|) | gross(=Σ\|netGEX\|) | net/gross |
|------|------|-------|-----------|
| IWM | 0.63B | 4.04B | **15.7%** |
| SMH | 0.13B | 0.63B | **20.5%** |
| SPY | 10.27B | 21.41B | 48.0% |
| GOOGL | 0.19B | 0.39B | 49.0% |
| META | 0.35B | 0.52B | 67.4% |
| DIA | 0.51B | 0.69B | 73.5% |
| QQQ | 8.07B | 10.95B | 73.7% |
| MSFT | 1.94B | 1.94B | 100.1% |

IWM は net が gross の 1/6 しかない。**「IWM の totalGEX が薄いから脆い」という読みは誤り**で、実際は厚いが均衡した板である。
記事で SMH（−102M）や IWM を「薄い」と書いていた箇所は、この意味で不正確だった。

分布のばらつきも net は極端（p5=0.13, p95=2.88）で、median20 で正規化しても安定しない。gross/near は p5≈0.5, p95≈2.3 と扱いやすい。

## 2. 厚み比と翌日値幅（N=20、n=224）

指標 = `near_today / median20(near)`。翌日 |リターン| を五分位で集計:

| 五分位 | 厚み比レンジ | 翌日値幅 中央値 | 平均 | p90 |
|--------|-------------|----------------|------|-----|
| Q1（薄い） | 0.39〜0.72 | 1.42% | 2.57% | **6.02%** |
| Q2 | 0.73〜0.93 | 1.15% | 1.91% | 3.40% |
| **Q3（平常）** | 0.94〜1.12 | **0.88%** | **1.14%** | **2.21%** |
| Q4 | 1.12〜1.40 | 1.12% | 1.52% | 3.43% |
| Q5（厚い） | 1.43〜5.03 | 1.74% | 1.98% | 4.44% |

**平常（Q3）が最も静かで、薄い側・厚い側の両方で値幅が広がるU字**。
厚い側で値幅が出るのは直感に反するようだが、**決算やSQ前にガンマが積み上がる**ため、「厚い＝イベント接近のシグナル」と解釈すると整合する。

このU字は N=10 / N=15 / N=20 のいずれでも再現した（Q3の中央値が最小: 0.84% / 0.61% / 0.88%）。窓長の感度は低く、**N=20 を採用**してよい。

## 3. 指数では効かない

| 対象 | n | Q1中央値 | Q3中央値 | Q5中央値 |
|------|---|---------|---------|---------|
| 指数のみ（SPY/QQQ/IWM/SMH/DIA） | 95 | 0.80% | 0.65% | 0.57% |
| 個別のみ（M7等） | 129 | 1.79% | 1.19% | **2.23%** |

指数はそもそも日々の値幅が小さく、厚み比による差がノイズに埋もれる（U字も出ない）。
**この指標は個別銘柄向け**であり、指数のレジーム判断には従来どおり Spot vs HVL の距離と Wall 位置を使う。

## 採用する定義（暫定）

```
near      = Σ|netGEX| over strikes where |strike/spot - 1| <= 0.10   # profile.total より
厚み比    = near_today / median(near の過去20営業日)
```

| 厚み比 | ラベル | 記事での扱い（個別銘柄のみ） |
|--------|--------|------------------------------|
| < 0.8 | 薄い | 板が平常より薄い。壁が効きにくく値が飛びやすい |
| 0.8〜1.4 | 平常 | 最も静かなゾーン。特記不要 |
| > 1.4 | 厚い | 板が積み上がっている。**決算・SQ等のイベント接近を疑い**、壁の強さと同時に値幅拡大も警戒 |

しきい値 0.8 / 1.4 は分位（p25≈0.81, p75≈1.37）とU字の底（Q3=0.94〜1.12）の双方に整合する。

## 限界（重要）

- **サンプルが小さい**: 41営業日・12銘柄・n=224、かつ移動窓が重複しているため独立サンプルではない。統計的有意性は主張しない。
- 期間が 2026年6〜8月の一相場のみ。レジームの異なる期間では閾値が動きうる。
- 翌日リターンは levels JSON の `spotPrice` 差分であり、実際の日中値幅（High−Low）ではない。**日中のボラは過小評価**されている。
- 「厚い＝イベント接近」の解釈は、決算日カレンダーと突き合わせて未検証。

→ **当面はレジーム確信度を機械的に掛け算する用途には使わず、記事に添える文脈情報として運用する**。データが 100営業日程度たまった時点で再検証すること。
